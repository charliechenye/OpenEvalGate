# Experimental Promptfoo producer example

This synthetic, offline handoff supports **Promptfoo 0.123.1**. It is not
production evidence, adoption evidence, or an official integration. OpenEvalGate's
deterministic core never executes Promptfoo or a model API.

From the repository root, after [installation](../../../docs/installation.md):

```bash
python scripts/run_promptfoo_demo.py --output /tmp/oeg-promptfoo-pass
python scripts/run_promptfoo_demo.py --output /tmp/oeg-promptfoo-blocked --blocked-controls
```

Use new directories. Both import the same five passing results. The second
exits `1` with `missing_rollback` / `missing_monitoring`. The demo adjusts its
copied synthetic review context to the fixture timestamp. The real producer
never updates a team's controls or context. Canonical reports stay unchanged.

Follow the [full tutorial](../../../docs/integrations/promptfoo.md) to use your
own results. [review.yml](review.yml) is a consumer-repository template: edit
metadata/paths and pin a published commit containing the scripts.

## Recreate the upstream fixture

`fixtures/export.json` is an unedited export actually generated by
`promptfoo@0.123.1`. `fixtures/provenance.json` records the version, synthetic
status, command, and source/output hashes. Fresh eval IDs, timestamps, and
performance counters vary. Byte reproducibility applies to converting the
same saved export, not generating a new eval.

With a Node version supported by Promptfoo, run from this directory:

```bash
export PROMPTFOO_CONFIG_DIR="$(mktemp -d)"
export PROMPTFOO_DISABLE_TELEMETRY=1
export PROMPTFOO_DISABLE_UPDATE=1
npm exec --yes --package=promptfoo@0.123.1 -- \
  promptfoo eval --config promptfooconfig.yaml \
  --output fixtures/export.json --no-cache
```

The provider returns predefined `vars.observation` and the assertion checks
the route; no model/service call occurs. The config has explicit identities
and one prompt/provider pair. After changing config, provider, or export,
update all three SHA-256 entries and generation metadata in
`fixtures/provenance.json`, then run
`python -m pytest tests/test_promptfoo_producer.py -q` from the root.
